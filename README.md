# Student-Performance-Analysis
Data Mining - Student Performance Analysis

# About Project
Student academic performance is influenced by several factors, including class attendance, study habits, internal assessment results, assignment completion and previous academic achievement. Educational institutions routinely maintain records of these factors, but the information may be distributed across different registers, spreadsheets or learning-management systems. When the records are examined only at the end of a term, opportunities to identify students who may need academic support can be missed.
The need addressed by this project is the ability to organize and analyze academic indicators in a consistent way. A basic predictive analysis can demonstrate how patterns in historical records may be used to estimate a performance category. Such analysis can help teachers and academic support teams explore relationships between study-related indicators and examination outcomes.
The project does not represent a commissioned system for a specific institution. It is an academic prototype prepared to demonstrate data-mining concepts using a synthetic dataset. Synthetic data is used because real student records are private and should not be collected or processed without appropriate permission, safeguards and a clearly defined purpose.
